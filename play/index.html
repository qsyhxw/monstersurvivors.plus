FAQ

Browser Version Questions

Is this the VOODOO Monster Survivors App?

No. This is the separate browser version. App heroes, gear, Gilded Cores, permanent upgrades and account-build guides do not apply here.

What should I do if my game screen looks different?

Open the version comparison first. It explains when to use the App guides and when to stay on browser pages.

How do I control the browser game?

Use WASD or arrow keys to move. Attacks happen automatically, and you can click or tap upgrade choices when the game offers them.

Why is the game still loading?

The game loads inside an embedded browser frame, so slower connections or restricted networks can take extra time. Wait a moment before refreshing, and try fullscreen only after the frame responds.

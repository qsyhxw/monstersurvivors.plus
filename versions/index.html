Monster Survivors App vs Browser Version

Check which Monster Survivors you are playing before following a build, weapon, hero, gear or upgrade guide. The VOODOO App and the FreezeNova browser version use different routes.

Check My Version Browse App Guides

Quick answer

Use App guides if you play the VOODOO App.

Look for package games.rivvy.monstersurvivors, App-style heroes, gear, Gilded Cores or permanent upgrades.

Use Play Online if you opened the browser game.

The FreezeNova browser version has its own controls, run flow and local browser experience. App builds and gear advice do not apply there.

Warning

Stop Before Copying a Build Across Versions

A weapon name, hero name or upgrade idea can look useful while still belonging to the wrong version. If the screen, progression system or entry point does not match, switch guides before spending resources.

Safe for App guides

  • Build planning for a long-term App account.
  • Hero, gear and weapon-role decisions.
  • Gilded Core and permanent upgrade choices.

Keep on browser pages

  • WASD, arrow-key and iframe loading issues.
  • Unblocked access and online play questions.
  • Browser-only weapon or map routes.

Version note for guides

If Your Game Looks Different, Come Back Here

App pages on this site are written for the VOODOO Monster Survivors App. The separate browser game has a smaller web-play focus, so App heroes, gear, Gilded Cores and permanent account routes should not be used as browser instructions.

FAQ

Version Questions

Are the App and browser version the same game?

No. Treat them as separate versions. App guides on this site cover the VOODOO App and package games.rivvy.monstersurvivors. The Play Online page is for the separate browser version.

Which version are the build and tier list pages for?

The current build, tier list, best weapons, best gear, Gilded Cores and upgrades pages are App-first pages. Use them when your question is about App account progression.

Where do I go for the browser game?

Use Play Online. If the page is blocked or loading poorly, use the unblocked and online/offline FAQs instead of App progression guides.

Can I use browser weapon advice in the App?

Only use advice when the game screen and system match. Browser-only weapon routes, map routes or evolution advice should not be applied to App gear, hero or resource decisions.

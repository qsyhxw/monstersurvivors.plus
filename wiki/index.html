FAQ

Monster Survivors Wiki Questions

Which Monster Survivors game does this Wiki cover?

It covers the App published by VOODOO under package games.rivvy.monstersurvivors. The site's Play Online page hosts a separate FreezeNova browser game with different progression.

Where should a new player start?

Start with the Beginner Guide, keep one developed general hero ahead and use complementary weapon roles. Open upgrades and gear only when those resources become the next real decision.

Does the Wiki provide exact drop rates and costs?

It does not present a fixed public table as universal. Rewards, prices, events and menus can change, so confirm exact quantities and results on the current App screen.

Where can I compare heroes and weapons?

Use the Heroes Tier List for long-term hero investment, Best Weapons for individual roles, Weapon Combos for slot balance and Best Builds when every system needs to work together.
